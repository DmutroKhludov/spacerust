# SpaceRust Launcher & Client (Аналог RustMe)

Полностью независимый проект: **собственный автономный лаунчер** и **изолированный игровой клиент Minecraft 1.16.5 (Fabric)**, созданный по образу и подобию **RustMe**.

Лаунчер **не зависит от TLauncher или `.minecraft`** — игра работает в собственной изолированной директории `%APPDATA%\.spacerust`, точно так же, как RustMe работает в `.rustme`.

---

## 📁 Структура проекта

* `run_launcher.py` — главный процесс нативного безрамочного лаунчера (на базе WebView2 и Python).
* `client_manager.py` — движок управления клиентом: проверка целостности, синхронизация библиотек, natives и запуск с аргументами `--gameDir %APPDATA%\.spacerust`.
* `index.html` + `css/` + `js/` — интерфейс главного меню в милитари-стиле RustMe:
  * Список серверов с живым онлайном и пингом.
  * Ползунок выделения оперативной памяти (2 — 16 GB).
  * Выбор и смена никнейма с 3D-головой скина.
  * Новости, промокоды (`WIPE2026`, `RUSTME`) и магазин доната.
  * Фирменная большая кнопка **«ИГРАТЬ»**.
* `spacerust-mod/` — исходники клиентского мода Fabric 1.16.5:
  * Меню крафта на клавишу **`Q`** (`RustCraftingScreen.java`).
  * Метаболизм в правом нижнем углу: HP, Еда, Вода, Радиация, Комфорт, Кровотечение (`RustHudOverlay.java`).
  * Тактический динамический прицел и хитмаркеры (`RustCrosshairOverlay.java`).
  * Оружейный движок: АК-47, Томпсон, Револьвер, Болт, отдача и HUD патронов (`GunManager.java`, `GunHudOverlay.java`).
* `Start_Launcher.bat` — быстрый запуск лаунчера в один клик.
* `Build_EXE.bat` — компиляция лаунчера в автономный исполняемый файл `.exe`.

---

## 🚀 Как запустить

### 1. Быстрый запуск
Дважды кликните по **`Start_Launcher.bat`** (или выполните `python run_launcher.py`).
Откроется темное безрамочное окно лаунчера. Выберите сервер, введите никнейм и нажмите **«ИГРАТЬ»**!

### 2. Сборка в один автономный `.exe`
Запустите файл **`Build_EXE.bat`**. Он автоматически:
1. Соберет мод `spacerust-mod-1.0.0.jar`.
2. Установит его в `.spacerust/mods`.
3. Скомпилирует `SpaceRust_Launcher.exe` в папке `dist/SpaceRust_Launcher/`.

## 🎯 Почему это независимый лаунчер (как RustMe)?
1. **Своя папка игры**: все файлы хранятся в `%APPDATA%\.spacerust` (не трогая `.minecraft` и не требуя TLauncher).
2. **Своя версия**: клиент зарегистрирован как `SpaceRust-1.16.5`.
3. **Прямое подключение**: при нажатии кнопки «ИГРАТЬ» лаунчер сразу заводит игрока на выбранный сервер RustMe/SpaceRust.
4. **Вшитый модпак**: кастомные худы, меню крафта на `Q`, отдача и прицелы загружаются автоматически.
